# Quick commands

A small **/** button in each Claude terminal's pane header opens a menu of slash commands: `/compact`, `/clear` and
`/context` to begin with, or any you set. Picking one types it into that Claude, the safe way: only while Claude waits
at its prompt with an empty input box, and Enter only once the box shows exactly that command. When the box holds
text you haven't sent, or a menu is open, it says so and types nothing.

`/clear` and `/compact` ask for a second click first (a setting turns that off). While Claude works, the menu shows
its commands dimmed until the turn ends.

Settings: the commands, separated by commas (a command may take words after it, such as `/model sonnet`; up to 12),
and the second click. It needs the **type** permission, used only for the command you pick.
