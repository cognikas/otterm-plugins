# Themes pack

Three more themes, each for the whole page and the terminals:

- **High contrast**: white on black, with strong status colors and clearer lines.
- **Warm dark**: cream on dark brown, with an amber accent.
- **Soft light**: dark gray on warm paper, gentler than Look's light theme.

Pick one in its settings. While the plugin is on, its theme shows instead of Look's (Look's focused border still
applies); switch the plugin off to go back to Look's theme. With Soft light, set Claude Code's own theme to a light
one with `/config`, so Claude's text reads well on it.

It needs no permissions: it sets the page's color tokens and the terminals' colors, and nothing else.
